## 🚀 How to Run & Preview

### Option 1: Open Directly in Any Web Browser
Simply double-click `index.html` or right-click `index.html` and select **Open with > Chrome / Edge / Firefox**. No build step or installation required!

### Option 2: Run with Local Node.js Server
Run the included static server using Node:
```powershell
node server.js
```
Then visit:
```
http://localhost:4173/
```
